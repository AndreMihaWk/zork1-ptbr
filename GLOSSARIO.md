# Glossário

Termos fixos da tradução. Todo texto do jogo usa os nomes desta lista. Para
propor outra tradução, abra uma Issue ou comente no Pull Request.

Gênero: (m) masculino, (f) feminino, (pl) plural. O gênero define os artigos
que o jogo escreve ("o lampião", "a lanterna"). Veja o
[guia de tradução](docs/TRADUCAO.md).

## Mantidos como no original

grue, zorkmid, Frobozz, Flathead, Dungeon Master, Zork, xyzzy, plugh e os
nomes próprios de lugares (Aragain, Hades, Atlântida com acento).
